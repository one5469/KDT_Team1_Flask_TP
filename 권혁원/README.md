# 쓰레기는 제거해야 한다 — 재활용품 분류

폐기물 분류를 진행한 3인 팀 프로젝트에서 재활용품 이미지 분류와 DB 구성을 담당했습니다.

- 기간: 2024.04.19–2024.04.22
- 담당: 권혁원 / 재활용품 분류 모델, DB 구성
- 데이터: cardboard, glass, metal, paper, plastic의 5종 재활용품 이미지
- 기술: Python, CNN, 이미지 증강, Flask

## 담당 작업

- 분류가 모호한 이미지를 정리하고 클래스별 학습 데이터 구성
- 회전 등 이미지 증강을 적용해 클래스별 데이터 수 조정
- CNN 이미지 분류 모델 학습 및 과적합 완화를 위한 조건 조정
- 웹 화면에서 재활용품 이미지의 분류 결과를 확인하는 기능 작업
- YOLO와 Faster R-CNN을 활용한 객체 탐지 적용 시도

## 자료 및 코드

- [발표자료](../docs/recycling-presentation.pdf): 개인 작업 부분은 PDF 38–69쪽
- 현재 개인 폴더에는 당시 구현 소스가 보존되어 있지 않습니다. 작업 내용과 예측 화면은 발표자료에 남아 있습니다.
- 객체 탐지는 확장 실험 단계였으며, 주요 구현 결과는 5종 재활용품 분류입니다.
